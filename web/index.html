Preparar imagen

Elige un ZIP del proyecto, un archivo local o una URL directa a PNG, JPEG, GIF o BMP. PNG requiere RGB de 8 bits sin entrelazado; GIF usa el primer fotograma.

Coloca el ZIP en imagenes/, sin descomprimirlo, y actualiza la lista.

Usa letras, números o guiones y un nombre nuevo. Solo se prepara una imagen a la vez; las demás siguen disponibles.

Selecciona un ZIP y una imagen.

JPEG/GIF/BMP: hasta 64 MiB y 16 millones de píxeles. La transparencia se compone sobre blanco.

Cerrar este panel no cancela la preparación. Mantén el servidor encendido. Una subida de imagen requiere mantener la pestaña conectada hasta terminar el envío. Se guardan bloques en data/: cambiar el origen no elimina el espacio necesario.

Preparar imagen

Incorpora una imagen al visor. Para imágenes grandes, utiliza un ZIP del proyecto.

Coloca el ZIP en imagenes/, sin descomprimirlo, y actualiza la lista.

Recomendado para archivos pequeños. La subida por fragmentos puede tardar mucho con archivos de varios GB; para ellos usa ZIP del proyecto. Mantén esta pestaña conectada hasta terminar el envío.

Debe ser un enlace público HTTP/HTTPS directo a una imagen, no a una página o carpeta de Drive. El servidor necesita internet para descargarla.

Usa letras, números o guiones y un nombre nuevo. Solo se prepara una imagen a la vez; las demás siguen disponibles.

Selecciona un ZIP y una imagen.

Formatos y límites

PNG: RGB de 8 bits sin entrelazado. JPEG/GIF/BMP: hasta 64 MiB y 16 millones de píxeles; GIF usa el primer fotograma y la transparencia se compone sobre blanco.

Cerrar este panel no cancela la preparación. Mantén el servidor encendido y espacio libre para guardar la imagen preparada.

# Instrucciones del proyecto PRIB

- El usuario requiere comentarios explicativos en el código de todas las etapas.
  Explicar responsabilidades, decisiones y lógica no evidente en español; evitar
  comentarios que solamente repitan cada instrucción.
- Implementar por etapas con comprobaciones reproducibles y documentación acorde
  a lo realmente implementado. No presentar decisiones propuestas como funciones listas.
- Java 21; conservar la compilación y las pruebas sin internet.
- No cargar las imágenes grandes completas en memoria ni añadirlas a Git.
- Mantener la solución compacta y justificar cualquier dependencia nueva.
